# Native third-party notices — supplement

Read together with the npm package root's `THIRD_PARTY_NOTICES.md`. The native
`client-cffi` and `client-core` code is covered by the root MIT `LICENSE`.
The shared dependency versions use the notices in the root file. This supplement
reproduces MIT license texts for native-only crates and versions that differ from
the wasm dependency graph. Proc-macro crates are included conservatively even
though they execute during compilation. `RUST_STDLIB_LICENSE.html` contains the
pinned native Rust toolchain's full standard-library copyright and license notice.

`release/native/notices.sh` checks every native target's normal dependency graph
against the root file and this supplement; a new crate/version must be documented
before packaging. When adding an entry, copy its actual LICENSE text from the
locked Cargo source, including copyright lines. Do not substitute a generic MIT
license. Keep the exact `## name version` heading so the coverage check can find it.
